# ViperNet Membership Service

- This is the clean standalone public candidate for optional ViperNet membership.
- ViperNet clients must remain fully usable without an account.
- Never add personal subscriptions, provider credentials, private file-service integration, private endpoints, or secret-bearing logs.
- Production deployment requires explicit approval, PostgreSQL, real mail delivery, backup/restore rehearsal, and an independent security review.
- Keep client credentials read-only and revocable. Never place access credentials in URLs, browser storage, or logs.
- Do not add a public remote, deploy this service, or publish source without the product owner's explicit approval.
