# Reporting a security issue

Please report suspected vulnerabilities privately to [support@vipernet.app](mailto:support@vipernet.app). Do not open a
public issue for an unpatched security problem.

Include the affected repository and revision, the conditions needed to reproduce the issue, and its practical impact. Do
not send passwords, subscription URLs, access tokens, configuration exports, or real member data. Use synthetic accounts
and credentials when sharing reproduction steps.

The ViperNet maintainers will review the report and coordinate a fix and disclosure. This contact is for security issues;
general support questions should use the address listed on [vipernet.app](https://vipernet.app).
